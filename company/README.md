# company — 会社方針・共通ルール

このディレクトリは、Studio CHOTTO Bit 全体に適用する方針とAI作業ルールを管理する。個別企画の進捗・原稿・作品設定はここに重複させず、各 `products/{product}/` を参照する。

## どのファイルを読むか

| ファイル | 正本として管理する内容 | 読むタイミング |
|---|---|---|
| [policy.md](policy.md) | 経営目的、優先順位、オーナー承認が必要な事項、GitHubの位置づけ、公開・宣伝の方針 | 全作業の開始時・重要判断時 |
| [ai-role.md](ai-role.md) | 体制と役割分担、AI共通の作業開始手順、討議、成果物の扱い | AIが作業を始めるとき |

## 情報の正本

- 会社の判断原則・承認：`policy.md`
- AIの作業手順・役割分担：`ai-role.md`
- 個別企画の詳細：各 `products/{product}/` のREADME・CANON・STATUS
- 移行前（〜2026-10）の議論と対象外プロダクト：旧リポジトリ（dragongongon/studio-maane、アーカイブ）

## 重複を防ぐルール

1. ルールの詳細は上表の正本に一度だけ記載し、他のファイルではリンクで参照する。
2. 個別企画固有の決定・状態・例外は、その企画の資料に記録する。
3. 変更時は、関連ファイルとの矛盾がないか確認する。
