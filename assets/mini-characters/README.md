## 使い方のルール

- **採用ラインは3頭身**。2頭身（mini-rui-2toushin.png）は比較検討時の参考保存で、採用しない。
- **動きクリップ（motion/）は音声を使わず、必ず無音で動画に入れる**。生成クリップに付いている音声は るい の声ではない。声は VOICEVOX が正本（るい＝春日部つむぎ）。
- 動きクリップがあるのは今のところ るい のみ。他キャラの動きが必要になったら、そのキャラのミニ静止画を元に同じ型で作る。
- ミニ版は正本（公式設定画・番組衣装版）の代替ではない。元絵は `../canonical-characters/` と `../host-design-tests/` が正本のまま。
