# モーションデザイン原則（まる・ミニキャラ用）

出典：LottieFiles「motion-design-skill」（MIT、https://github.com/LottieFiles/motion-design-skill ）の要点を、動画制作（30fps）向けに読み替えて転記したもの。2026-11-19 取り込み。

前提：まる の造形ルールは不変（球体＋顔だけ、変形なし、動きは球全体の移動・回転のみ）。以下のイージングはすべて「位置と回転の軌跡」にかける。大きさの伸縮でオーバーシュートを作らない。

## イージングの使い分け

- 入場（現れる動き）：ease-out 系。速く出て、ゆっくり収まる。
- 退場（消える動き）：ease-in 系。ゆっくり出て、速く去る。
- 空間移動に linear（等速）は使わない。
- 跳ねの着地（Bounce settle）のベジェ目安：cubic-bezier(0.175, 0.885, 0.32, 1.275)。

## 感情 → 動きの対応

- 喜び・楽しさ（Playful）：ease-out-back ＋ 弧を描く軌跡。オーバーシュートは軌跡上で 10〜20%。
- 弾む素材感を出したいとき：オーバーシュート 15〜25%（軌跡の行き過ぎとして表現）。
- 驚き：短い Anticipation（逆方向への小さな予備動作）を入れてから大きく動く。
- 落ち着いた場面：オーバーシュートなしの ease-out、時間は長め。

## 振り付け（Choreography）

- Anticipation（予備動作）→ 本動作 → Follow-through（着地後の小さな揺れ・弾み）の3段で作る。まる の既存テスト「跳ね＋着地で小さく2回弾む」は Follow-through に当たる。
- 副次モーション（Secondary layer）：足元の影は本体より少し遅らせて付ける（元資料は 50ms ≒ 30fps で 1〜2 フレーム）。
- 複数要素を動かすときは同時ではなく stagger（少しずつずらす）。ずらし幅の総量は全体の 1/3 以内に収める。

## 時間の目安（動画向け読み替え）

- 元資料の duration 表は UI 前提（80〜1200ms）。動画では「動きの距離が大きいほど時間を長く」を原則に、フレーム数へ換算して使う。
- まる の短い反応モーションは 0.3〜1.0 秒、場面をまたぐ移動は 1〜2 秒を目安に調整する。

## チェックリスト

- [ ] 移動に等速を使っていないか
- [ ] 入場は ease-out、退場は ease-in になっているか
- [ ] 着地・停止に Follow-through があるか
- [ ] 影などの副次モーションが少し遅れて付いているか
- [ ] まる の変形（伸縮・顔の描き直し）をしていないか
