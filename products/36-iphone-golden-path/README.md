# P36：『「黄金のルート」』——初代iPhone発表デモと、本番の設計

2007年1月9日、スティーブ・ジョブズは「iPod、電話、インターネット通信機器」を1台に融合した初代 iPhone を発表した。歴史に残る完璧なデモは、しかし、約100台しかない不安定なプロトタイプを「黄金のルート」と呼ばれる特定の操作順序の上でのみ動かす綱渡りだった。電波表示は常に5本に固定され、客席では開発陣がスコッチのフラスコを回していた。並行して、ポケットの鍵で傷付いた画面への怒りから、Corning の化学強化ガラスを半年で量産へ持ち込むもう一つの綱渡りが進む。「未完成のものを本番で動かすための設計」を描く note 企画。P30〜P35に続く「歴史的転換点」シリーズの一編。

**現在地：初稿完成、5者レビュー回収と統合、ブラッシュアップ反映（B案）まで完了した（2026-10-29）。タイトルは『「黄金のルート」』——初代iPhone発表デモと、本番の設計に決定（2026-10-29）。価格は ¥500 に決定（2026-10-29、全製品 ¥500 統一のオーナー決定）。残件は DeepReview（枠待ち）・テーマ画像の repo 格納・最終確認と note 下書きで、noteへの公開・販売は未実施。詳細は STATUS.md。**
