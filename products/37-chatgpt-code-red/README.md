# P37：『「コード・レッド」』——ChatGPT公開から、Googleが出すまでの約2か月

2022年11月30日、OpenAI は ChatGPT を無料の「リサーチプレビュー」として公開した。5日で利用者は100万人を超え、2か月で月間約1億人に達した。一方、対話 AI の技術を持ちながら一般公開に踏み切れなかった Google には、ニューヨーク・タイムズの報道によれば「コード・レッド」と呼ばれる緊急体制が敷かれ、創業者が戦略会議に戻った。慌てて発表した Bard は宣伝デモの誤答で時価総額約1,000億ドルを失う。「既存事業が新規を止める構造の点検」を描く note 企画。P30〜P36に続く「歴史的転換点」シリーズの一編で、新ケイデンス方針（無料3部＋有料1部）の最初の製品。
