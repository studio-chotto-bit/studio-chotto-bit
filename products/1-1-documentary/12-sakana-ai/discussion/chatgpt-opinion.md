サカナAI企画レビュー

結論から言うと、企画としてかなり有望です。私は採用に賛成です。

ただし、現状のブリーフには一つ大きな修正を勧めたい点があります。

それは、作品の中心を「サカナAIという急成長企業の物語」に寄せすぎないことです。

この作品の本当の価値は、サカナAIの企業紹介でも、日本発ユニコーンの成功物語でもありません。

Transformerを生んだ技術思想の中心にいた研究者が、次のAIの進化について、別の可能性に賭けた。その賭けは技術的にどこまで成立しているのか。

ここに焦点を絞るべきです。

企画ブリーフと裏取りラウンド1の両方を読めました。ファイルの内容も確認できています。特に、Model Mergeの査読掲載と、ベンチマーク数値が発表者自身によるものであるという区別は、記事の信頼性を支える重要なポイントです。

以下、5項目について率直に述べます。

## 1. 記事の柱として成立するか

成立する。強い柱になる

私はこの企画の最大の魅力は、人物と技術思想の対比にあると思います。

構造を整理すると、こうです。

2017年

Attention Is All You Need

Transformerの登場。Llion Jonesは8人の共著者の一人。

その後

スケーリングの時代

計算資源・データ・パラメータを拡大することでAIの性能を高める競争。

2023年

サカナAI創業

Jonesが東京で新しい研究開発企業を立ち上げる。

2024年以降

Evolutionary Model Merge

巨大な単一モデルを作る競争とは異なる、既存モデルの進化的な融合というアプローチ。

この構成には、ドキュメンタリーとして優れた逆説があります。

特に良いところ

① P30との対になる。

P30がTransformerの誕生を扱った作品なら、こちらはその発明に関わった人間が、その先にどんな可能性を見ているかを扱う作品です。

単なる続編ではありません。

P30：AIの世界を変えた技術はどう生まれたか

P12：その技術を生んだ時代の次に、何が来るのか

という関係にできます。

これはStudio CHOTTO Bitのドキュメンタリーシリーズの中でも、作品間のつながりを生み出す良い設計です。

② 人物の経歴が技術的な問いに直結している。

著名な研究者がスタートアップを立ち上げた、というだけならよくある企業紹介です。

しかし今回は、Transformerの共著者という経歴が、そのまま記事の問いの意味を強くします。

③ 日本という舞台にも意味がある。

世界的なAI研究の中心にいた人物が東京で創業したことは、日本のAI産業を考える読者にも興味を持たれるでしょう。

ただし、修正すべき表現がある

ブリーフの「巨大化の競争から降りた」という表現は、少し強すぎます。

Jonesがスケーリング競争を完全に否定した、あるいはサカナAIが巨大モデルの開発を放棄した、と読めてしまうからです。

これは避けたい。

例えば、

巨大化競争とは異なる道を探した

巨大モデル一辺倒ではないAIの進化を目指した

スケーリングだけではない、もう一つの可能性に賭けた

くらいが適切です。

「降りた」は記事のキャッチコピーとしては魅力的ですが、事実認定としては慎重に扱うべきです。

この区別は重要です。

## 2. 有料部の問いは適切か

方向性は良い。ただし問いを少し精密にしたい

現在の問い：

進化的モデルマージは、スケーリングの代替に本当になるのか

これは読者を引きつける問いです。

ただ、技術的には少し二項対立が強いと思います。

問題点

スケーリングとEvolutionary Model Mergeは、必ずしも同じ条件で競争する技術ではありません。

スケーリングはモデルの規模や計算資源などを拡大して性能を向上させる考え方。

Evolutionary Model Mergeは、既存モデルの組み合わせ方を進化的に探索するアプローチです。

したがって、モデルマージが成功しても、それだけでスケーリングが不要になったとは言えません。

例えば、

小規模モデルで十分な性能を実現できる領域があるか

既存モデルを融合することで開発コストを下げられるか

大規模モデルと組み合わせて使うことで性能を高められるか

融合によって元のモデルが持っていた能力を失わないか

という複数の論点があります。

ここを曖昧にすると、記事の結論が「どちらも重要です」という当たり前の話になりかねません。

私の推奨する問い
第一候補

進化的モデルマージは、AI開発のコストと性能の関係を変えられるのか。

技術的な優劣だけでなく、事業として成立するかまで検証できる問い。

第二候補

小さなモデルを組み合わせる戦略は、巨大モデルへの投資競争にどこまで対抗できるのか。

元の企画の逆説を最も強く引き継ぐ問い。

第三候補

モデルを作る競争から、モデルを進化させる競争へ。サカナAIの賭けは成立するのか。

ドキュメンタリーとしての物語性が強い問い。

私なら第一候補を採用します。

理由は、技術的な話を事業的な現実に接続できるからです。

有料部で検証すべき5項目

有料部は、単にModel Mergeの論文を解説するだけでは500円の商品として弱いです。

次の5項目で検証台帳を構成することを提案します。

検証項目 / 確かめること

① 性能 / 本当に性能が向上するのか

② コスト / 学習・探索・推論を含めて安くなるのか

③ 再現性 / 第三者も同じ成果を出せるのか

④ 適用範囲 / どんなモデル・タスクに有効なのか

⑤ 事業性 / 顧客が実際にお金を払う価値があるのか

特に③と⑤が重要です。

論文が査読を通ったことと、企業が継続的に利益を出せる技術であることは別です。

また、mergekitなどへの実装は外部での利用可能性を示す材料ですが、それ自体が性能の独立再現や商用採用の証明ではありません。

ここは丁寧に分けたいです。

もう一つ、技術的に重要な指摘

Evolutionary Model Mergeの説明では、「小さなモデルを融合する」という表現だけでは不十分です。

裏取り資料にあるように、進化アルゴリズムで探索するのはモデルの単純な組み合わせではなく、パラメータ空間やデータフロー空間におけるマージのレシピです。

つまり、モデルを交配させるという比喩は導入には使えても、技術説明では具体的な探索対象を示す必要があります。

さらに、評価に使う計算量や探索コストも検証対象に含めるべきです。

「巨大なモデルを学習しなくてよい」ことと「安価に高性能なAIを作れる」ことは同義ではありません。

最終的には、スケーリングの代替かどうかより、どんな条件でスケーリングより合理的になるのかを明らかにする。

これが記事の到達点として最も良いと思います。

## 3. 無料部のタイトル方向性

具体語＋人物の逆説を推奨

タイトルには、以下の3要素を使いたいです。

Attention

Llion Jones

サカナAI、または巨大モデル

ただし、無料部の段階で「進化的モデルマージはスケーリングを超えられるのか」という有料部の問いまで出してしまうのは避けたいです。

無料部では「何が起きたのか」を読ませ、有料部では「その賭けは本当に成立するのか」を読ませる構成が良いでしょう。

タイトル案

A / Attentionの共著者は、なぜ東京でサカナAIを創業したのか / 最推奨

B / Transformerを生んだ研究者が、巨大モデルとは違う道を選んだ / 逆説が強い

C / 「Attention」の次へ。Llion Jonesが東京で始めたAIの進化 / 知的・シリーズ感

D / 巨大モデルを作る時代に、小さなモデルの群れを作る会社 / 技術の対比が明確

E / サカナAIとは何者か。Transformerの共著者が選んだ次の挑戦 / 企業紹介寄り

私の推奨

A「Attentionの共著者は、なぜ東京でサカナAIを創業したのか」

これが最も良いと思います。

理由は3つ。

Attentionという具体的な固有名詞がある。

Jonesの経歴を知らない読者にも興味を持たせられる。

創業の理由を読ませる構造なので、有料部の技術的な検証を先取りしない。

Bも魅力的ですが、「巨大モデルとは違う道を選んだ」という表現は、Jones本人の思想を少し先回りして解釈しています。

タイトルとして採用するなら、本文でその意味を十分に裏付ける必要があります。

無料3部のタイトル構成案

記事全体のタイトルだけでなく、各部にも具体的な見出しをつけるなら、次のようにします。

第1部：Transformerの共著者は、なぜ東京に来たのか

第2部：モデルを交配させる。サカナAIが発表した新しい進化の方法

第3部：研究室から巨大企業へ。約4,320億円の評価を受けたAIスタートアップ

第3部については、評価額を見出しに使うなら、会社が公表した数字ではなく、2026年4月時点の会社発表に基づく評価額であることを本文でも正確に説明してください。

また、評価額だけでなくMUFGや大和証券との提携を扱うことで、研究成果が実際の顧客企業の業務に向かっていることを示せます。

ただし、提携発表と商用展開の実績は別物です。2026年8月の大和証券との本番開発フェーズ移行は、単なる提携発表より一歩進んだ材料ですが、売上規模や顧客満足度まで証明するものではありません。

## 4. IPO報道・評価額などのリスク

最も注意が必要な部分

ここは裏取りラウンド1の仕事を高く評価します。

特にIPOについて、報道と会社の公式見解を分けているのは正しいです。

① IPO報道の扱い

現時点の整理は次のとおりです。

2027年秋の上場観測 / 日経などが報道

IPO準備 / 関係者取材に基づく報道

ゴールドマン・サックスの関与 / 報道ベース

会社の公式見解 / 正式に決定した事実はない

上場の確定 / していない

ここで絶対に避けたいのは、

「サカナAI、2027年秋に上場へ」

「IPOを決めたサカナAI」

「上場を控えたサカナAI」

といった断定的な書き方です。

私なら次のように書きます。

2026年11月9日、日本経済新聞は、サカナAIが2027年秋の上場を視野に準備に入ったと報じた。共同通信やReutersなども関係者取材に基づいて報道した。一方、同社は「IPOを正式に決定した事実はない」とコメントしている。

これなら報道の存在と会社の姿勢の両方を伝えられます。

もう一つ重要なのは、IPO準備の報道を技術的成功の証拠にしないことです。

IPOを目指す企業だからといって、その技術が優れているとは限りません。

逆にIPOが実現しなかったとしても、研究成果が無価値になるわけではありません。

企業の評価と技術の評価は、別々に行うべきです。

② 評価額の扱い

ここは数字の出所を必ず区別してください。

シード / 約45億円 / 会社発表

シリーズA調達額 / 約300億円 / 会社発表

シリーズA評価額 / 約2,200億〜2,250億円 / 報道ベース

シリーズB一次クローズ / 約200億円 / 会社発表

シリーズB評価額（当初） / 約2.65Bドル / CEO発言を報道

シリーズB拡大後 / 約320億円 / 会社発表

拡大後評価額 / 約4,320億円 / 会社発表

特に重要なのは、2025年11月のシリーズB一次クローズと2026年4月の拡大後を混同しないことです。

ブリーフの数字は修正が必要です。

シリーズBについては、

2025年11月に約200億円で一次クローズし、その後、2026年4月に総額約320億円へ拡大した。

という時系列が適切です。

また、シリーズAの評価額約2,250億円は公式発表ではありません。

「評価額2,250億円で調達した」と断定してはいけません。

③ 私が追加したいリスク

もう一つ、企画の構造上のリスクがあります。

サカナAIの研究成果を、会社全体の技術的優位性と混同しないこと。

例えば、

Evolutionary Model Mergeの論文が査読掲載された

The AI Scientistが発表された

Darwin Gödel Machineが発表された

大企業との提携が発表された

これらはそれぞれ別の成果です。

一つの研究成果が評価されたからといって、会社のすべての研究が同じ水準で成功しているとは言えません。

また、研究発表、技術実証、顧客環境での本番運用、継続的な収益化は、それぞれ異なる段階です。

記事内でこの4段階を区別すると、企業広報の再構成ではない、検証型ドキュメンタリーとしての価値が高まります。

## 5. 公開タイミング

2027年前半の公開を推奨

ここは少し意外かもしれませんが、私は2027年秋のIPO前後を本命にするより、2027年前半に本編を公開し、秋に必要なら続編・追補を出す案を推します。

理由は3つあります。

理由① IPOに依存しない作品だから

この企画の本当のテーマはIPOではありません。

Transformerの次に何を作るのか

巨大モデル以外の進化の可能性はあるのか

研究成果を事業に変えられるのか

という問いです。

IPOは企業の成長を描くための材料の一つにすぎません。

上場が延期・中止になっても、記事の価値が失われない構成にするべきです。

理由② 秋まで待つと、技術の検証が後回しになる

IPOの話題性は確かに強いです。

しかし、2027年秋まで待っても、Model Mergeの技術的な評価が自動的に明確になるわけではありません。

むしろ、今のうちに研究成果と事業実績を整理した記事を出すことで、読者にサカナAIを見るための基準を提供できます。

理由③ 秋には別の角度で記事を作れる

2027年前半に本編を公開しておけば、秋には新しい情報を使って別の作品を作れます。

例えば、
